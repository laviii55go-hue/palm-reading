# 相談・決定事項 2025-03-24

## 本番で「📋 基本解釈（テンプレート）」になる件

- **状況**: Netlify に `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `GEMINI_API_KEY` は設定済みだったが、テンプレ表示になることがあった。
- **整理**: キー未設定だけでなく、**ランダムで選んだ1プロバイダが一時失敗**したときも従来は即フォールバックしていた。
- **決定**: API 側で **複数プロバイダを順に試行**し、Claude の **JSON フェンス**にも対応。運用面では一時的な API 側不調も考慮。

## 「花札画像を消して」の表現

- **初回の解釈**: トップ・裏面の PNG を削除しグラデーションに差し替え。
- **訂正**: ユーザー意図は **見出しの 🎴（絵文字）** の除去に近かった。**画像は元に戻し**、見出しから 🎴 のみ削除で合意。

## 楽天 `mtwidget05` の SyntaxError

- A8 連携変数が付いたときに別ドメインのスクリプトが絡み、JS として不正な応答になる可能性があったため、**インラインから A8 ネットワーク用変数を外す**方針。

## デプロイ運用
