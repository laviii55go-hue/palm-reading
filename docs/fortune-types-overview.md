# 占いサイト組み込み時の 難易度・問題点・版権 一覧

このドキュメントは、様々な占いを当サイトに組み込む際の参考資料です。

---

## 凡例

| 難易度 | 意味 |
|--------|------|
| ★☆☆ 低 | ロジックが単純、データ量少、実装しやすい |
| ★★☆ 中 | ある程度のデータ・ロジックが必要 |
| ★★★ 高 | 複雑な計算・大量データ・専門知識が必要 |

## 版権リスクが高いもの（要慎重）

1. **MBTI** … 商標・測定器の複製不可。「16タイプ」「性格タイプ」等で代替
2. **六星占術** … 商標の可能性。独自名称で類似占いを実装
3. **オラクルカード** … 各デッキの画像は著作権あり。テキストのみ or 自作イラスト
4. **新作タロット** … 現代のデッキは著作権あり。ウェイト版・マルセイユ版等のPD版を使用
